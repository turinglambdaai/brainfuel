# BrainFuel is ready

After installation, BrainFuel starts as a small quota card.

- Use **Refresh quota** to refresh GLM quota data.
- Use the top-right **⋯** app menu for Settings, software updates and About.
- The Windows installed build checks for software updates automatically in the background.

中文：安装完成后，主卡片底部的“刷新额度”只刷新额度数据；设置、软件更新与关于位于右上角“⋯”应用菜单。
