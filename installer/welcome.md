# BrainFuel

**GLM Coding Plan quota, at a glance.**

BrainFuel is a free and open-source desktop widget for monitoring your 5-hour and weekly GLM Coding Plan quota.

- Lightweight always-on-top quota card
- Automatic quota refresh and local notifications
- Windows delta updates for the installed build
- Source, checksums and build provenance published on GitHub

中文：BrainFuel 是一个免费开源的 GLM Coding Plan 额度桌面小组件，用于查看 5 小时与周额度，并支持自动刷新和本地提醒。
